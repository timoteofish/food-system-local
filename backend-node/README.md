# Backend Node.js

Nova API local do Food System. Esta pasta será expandida gradualmente enquanto o backend Rails em `backend/` continua funcionando como referência.

## Executar

```bash
npm install
copy .env.example .env
npm run dev
```

API: `http://127.0.0.1:3000`

O endpoint `/up` verifica o processo. O endpoint `/api/v1/health` verifica também a conexão com o MySQL.
