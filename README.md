# Food System Local

Food System Local is a restaurant management application focused on practical day-to-day operations, local data ownership, and affordable long-term use.

## What it offers

- Business, menu, category, and product management
- Table service, QR codes, and a public digital menu
- Order management and kitchen workflows
- Cash register, payment records, inventory, and recipes
- Delivery, customer and supplier records, discounts, and loyalty tools
- Operational reports, data backups, and restore workflows

The application is designed for a restaurant to run its core workflows from a local installation. Shared product improvements are delivered through common releases, while each installation keeps its own business data and settings.

## Current status

The project includes working local workflows for restaurant management, ordering, inventory, cash operations, and backups. Each installation is configured for one restaurant and does not provide individual employee accounts or per-employee permissions. Marketplace connections are not yet operational provider integrations, and fiscal documents are drafts only; the application does not issue legally valid invoices. Windows installation and release readiness still require validation on supported Windows systems.

The product is intended to reduce recurring software costs while remaining maintainable and extendable. Local operation depends on the application and its local data services being available. Features used by customer devices over a restaurant network require suitable network access.
